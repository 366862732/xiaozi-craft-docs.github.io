快速开始 ​

按照下面的步骤，可以快速查看和使用这份文档。

1. 安装依赖 ​

在项目根目录运行：

bash
npm install

2. 启动本地文档 ​

运行以下命令打开本地预览：

bash
npm run dev

3. 访问页面 ​

启动成功后，打开终端提示的本地地址，进入 开发指南 页面即可看到左侧导航栏。
