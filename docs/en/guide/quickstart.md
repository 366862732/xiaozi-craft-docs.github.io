# Quick Start

Follow the steps below to preview and use this documentation quickly.

## 1. Install dependencies

Run this command in the project root:

```bash
npm install
```

## 2. Start the local docs site

Run the following command to start the preview server:

```bash
npm run dev
```

## 3. Open the pages

After the command starts successfully, open the local URL shown in the terminal and go to the development guide pages from the sidebar.
